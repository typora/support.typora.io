## New

### Floating Editor Toolbar

<img src="/media/new-1.14/toolbar.png" alt="截屏2026-07-03 14.43.00" style="zoom:50%;" />

You can now enable the float toolbar from **menubar** → **View** → **Toolbar** or from **Settings** → **Appearance**.

### Config which files to show in sidebar

![截屏2026-07-03 14.44.13](/media/new-1.14/show-hidden-files.png)

- Provide options to show hidden files / folders in sidebar
- Provide options to show non-markdown files, or, you can config which files should be display or hidden in files sidebar.

## Improvements

<img src="/media/new-1.14/截屏2026-07-04 20.28.16.png" alt="截屏2026-07-04 20.28.16" style="zoom:50%;" />

The macOS version now also have context menu for setting styles, just like the Windows / Linux version.

## Bug Fixes

1. Fixed a list rendering regression.
2. Fixed list item issues on macOS 27.
3. Fixed CORS handling.
4. Fixed macOS export.
